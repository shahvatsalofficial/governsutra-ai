# Release Checklist

- [ ] `npm test` passes from a clean extraction.
- [ ] `npm run doctor` passes on supported Node.js versions.
- [ ] Offline demo runs without credentials or network.
- [ ] Secret/path traversal/symlink/oversize negative tests pass.
- [ ] Audit tampering is detected; limitations are documented.
- [ ] Every agent and skill has a bounded scope and output contract.
- [ ] IDE adapter files are validated against named host versions.
- [ ] Framework mappings are versioned and human-reviewed.
- [ ] No legal, certification, compliance or safety guarantee appears in product copy.
- [ ] License, dependency inventory, SBOM, security policy and release notes are correct.
- [ ] Human governance decision recorded for release.
